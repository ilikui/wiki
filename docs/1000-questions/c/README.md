**▎1000 问全景（问题库）**

▎ **基础语法与数据类型**

1. 声明（declaration）和定义（definition）的区别是什么？为什么这个区别在C里比在其他语言里更重要？

2. int在不同平台上可能是16位、32位或64位——写可移植代码时应该怎么处理整型长度问题？

3. unsigned和signed之间做算术运算时，C语言怎么隐式转换？什么情况下会出问题？

4. 浮点数float和double在内存里的存储格式（IEEE 754）是什么样的？判断两个浮点数是否相等为什么不能直接写==？


▎ **存储类与作用域**

1. auto、register、static、extern这四种存储类分别控制变量的什么属性？

2. static修饰局部变量、全局变量和函数时，行为各是什么？为什么static在C里被"重载"了？

3. const修饰变量和const修饰指针（const int \*p vs int \*const p）——编译器各保证了什么？

4. volatile是干什么的？它在嵌入式开发里最典型的场景有哪些？去掉volatile编译器会优化掉什么？


▎ **指针**

1. 指针到底是什么？它存的地址和这个地址上的内容为什么是两回事？

2. 指针加减整数（p+1）时，地址到底加了几个字节？这个机制跟指针类型有什么关系？

3. NULL指针、野指针、悬空指针（dangling pointer）——三种指针各是怎么产生的？怎么避免？

4. 函数指针是什么？把它作为回调函数使用时，编译器帮你做了什么？

5. 二级指针（int \*\*p）在什么场景下必须用？只用一级指针代替会出什么问题？


▎ **数组与字符串**

1. 数组名和指针是一回事吗？为什么sizeof(arr)和sizeof(ptr)结果不一样？

2. C语言为什么没有内置的字符串类型？以'\\0'结尾的字符串设计带来了哪些问题？

3. strcpy、strcat、sprintf为什么被称为"不安全"的函数？它们的安全替代版本是怎么解决长度问题的？

4. 二维数组在内存里是怎么排列的？为什么访问arr\[i\]\[j\]时，维度的顺序对性能有影响？


▎ **结构体与联合体**

1. 结构体内存对齐（alignment）是怎么回事？为什么编译器会在成员之间插入填充字节？

2. 位域（bit field）在什么场景下有用？用位域和手动按位操作各有什么优缺点？

3. 联合体（union）和结构体（struct）在内存布局上有什么本质区别？联合体最常见的用途是什么？

4. 结构体作为函数参数传值（pass by value）和传指针（pass by pointer）在性能上差在哪？


▎ **内存管理**

1. 堆（heap）和栈（stack）在C语言运行时里是怎么管理的？谁分配谁释放？

2. malloc的底层实现大概是怎么工作的？为什么malloc不一定每次调用都会去问操作系统要内存？

3. malloc之后必须free——"内存泄漏"具体是什么样的？一个程序泄漏了会怎么样？

4. 什么是"内存碎片"？为什么长时间运行的嵌入式系统要尽量避免动态内存分配？


▎ **位操作**

1. 移位运算（<<和>>）在符号数和无符号数上的行为一样吗？右移有符号数是算术移位还是逻辑移位？

2. 用位操作实现"取一个整数二进制表示中的第n位"——表达式怎么写？它和掩码（mask）的关系是什么？

3. 嵌入式驱动中常见的"读-改-写"模式（如设置某个寄存器的某几位）——用位操作怎么实现才算安全？


▎ **预处理器**

1. define定义的宏和真正的函数有什么本质区别？宏的"副作用问题"（如MAX(a++, b)）是怎么产生的？

2. 头文件里的 Include Guard 是干什么的？如果不加，编译器会遇到什么问题？

3. pragma once和Include Guard比有什么优缺点？为什么有些项目坚持用Include Guard？


▎ **文件I/O**

1. fopen的"文本模式"和"二进制模式"在Windows和Linux上的行为有什么不同？这跟换行符'\\n'的表示有什么关系？

2. fgets和gets有什么区别？为什么gets已经从C11标准里被移除了？

3. fread和fwrite的"块读写"设计——一次读4个256字节的块和一次读1个1024字节的块，性能一样吗？

4. 文件指针（FILE \*）和文件描述符（fd）——C标准库的IO函数和系统调用read/write之间隔了几层？


▎ **可变参数**

1. printf是怎么知道传入了多少个参数的？va\_list、va\_start、va\_arg、va\_end的机制是什么？

2. 自己写一个可变参数函数时，为什么必须有一个固定参数来确定可变参数的起始位置？

3. 可变参数函数为什么是"类型不安全"的？printf传错参数类型时，那个崩溃是怎么发生的？


▎ **函数与递归**

1. 函数调用时，栈帧（stack frame）里存了哪些内容？返回地址和局部变量的布局是怎么样的？

2. 递归函数为什么不遇到终止条件就会栈溢出？递归和非递归（迭代）之间，除了写法还有什么本质区别？

3. 尾递归优化（tail call optimization）是什么？它解决了递归的什么问题？编译器怎么知道可以做这个优化？


▎ **多文件组织与模块化**

1. 头文件应该放声明还是定义？为什么在头文件里定义全局变量会有"多重定义"问题？

2. "前向声明"和"环形依赖"——两个头文件互相包含时为什么会编译失败？怎么解决？

3. static函数在模块化编程里起什么作用？它和普通函数在链接时有什么不同？


▎ **未定义行为与常见陷阱**

1. 什么是C语言的"未定义行为"（undefined behavior）？为什么C有这么多UB而其他语言没有？

2. 缓冲区溢出（buffer overflow）是怎么发生的？一个简单的gets()如何能让攻击者改写返回地址？

3. 整数溢出（overflow）在符号数和无符号数上的行为分别是定义的还是未定义的？

4. 序列点（sequence point）是什么？为什么i=i++是未定义行为？

5. 看一段代码判断它有没有未定义行为——为什么这种能力区分了"会写C"和"真正懂C"？


▎ **标准库深入（stdlib.h / string.h / math.h）**

1. qsort排序需要一个比较函数指针——为什么标准库不直接内置一个默认的升序比较器？void \*参数在这里解决了什么问题？

2. bsearch（二分查找）要求数组是"已排序的"——如果传入一个未排序的数组，bsearch会怎么样？它能检测出来吗？

3. atoi把一个字符串转成整数，如果传入"abc"会返回什么？atoi、strtol、sscanf三者在错误处理上有什么不同？


▎ **编译与链接**

1. 从.c文件到可执行文件，经历了哪几个阶段？每个阶段产出了什么？

2. 静态链接和动态链接的本质区别是什么？嵌入式系统里为什么通常用静态链接？

3. "符号解析"和"重定位"在链接器里各做了什么？链接错误中的"undefined reference"和"multiple definition"分别发生在哪个阶段？

4. 为什么在头文件里定义全局变量并让多个.c文件包含，链接时会报多重定义？但如果加上static或inline就不会？


▎ **高级特性**

1. restrict关键字是干什么的？它对编译器优化有什么帮助？不加restrict的话编译器不敢做什么假设？

2. 柔性数组成员（flexible array member）——struct的最后一个成员写成char data\[\]而不是char \*data，两者在内存布局和分配方式上有什么不同？

3. C11引入的\_Generic泛型选择——它是怎么让一个宏根据参数类型展开不同代码的？跟C++的重载比，它缺了什么？


▎ **防御性编程与安全**

1. assert和static\_assert的区别是什么？为什么说static\_assert比assert更适合在嵌入式里做编译时检查？

2. MISRA C的核心规则可以归结为哪几条原则？它为什么要禁止动态内存分配（malloc/free）？

3. 什么是"永不失败的函数"和"可能失败的函数"的接口设计约定？在C里怎么用返回值表达错误？

4. 用errno报告错误和使用自定义错误枚举各有什么优缺点？AUTOSAR的Std\_ReturnType走的是哪种风格？


▎ **非局部跳转（setjmp / longjmp）**

1. setjmp/longjmp是干什么的？它和goto有什么本质区别？为什么说它是C里的"异常处理"？

2. longjmp跳回setjmp的位置后，栈上的局部变量会恢复成原来的值还是当前的值？这跟volatile有什么关系？

3. 在嵌入式里用setjmp/longjmp做错误恢复时有什么风险？什么场景下它是合理的？


▎ **信号处理（signal.h）**

1. 信号（signal）在C语言层面和在操作系统层面分别是什么？SIGSEGV（段错误）是怎么产生的？

2. 信号处理函数里能做什么、不能做什么？为什么说在信号处理函数里调用printf是危险的？

3. 什么是"异步信号安全"（async-signal-safe）函数？在嵌入式里，一个ISR和一个信号处理函数，谁的限制更多？


▎ **C标准演变**

1. C89、C99、C11、C17、C23——每个版本最重要的一条改变是什么？为什么C99被认为是C的"爆发版本"？

3. bool类型从C99的\_Bool到C23可以直接用bool——这个演变过程反映了C标准委员会什么样的设计哲学？


▎ **内联函数与VLA**

2. 变长数组（VLA）是C99引入的——它的长度在编译时未知，那它在栈上怎么分配？为什么C11把VLA改成了"可选特性"？


▎ **C与C++互操作**

2. 一个在C里合法的函数指针赋值（如void \*p = malloc）在C++里为什么需要强制转换？这反映了C和C++在类型系统上的什么差异？


▎ **对齐深入**
