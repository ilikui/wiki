**专栏⑱·分卷：朝代脉络问题库（全量）**

记录历史上下五千年的核心脉络：按朝代堆问题，每个问题都是深入了解一扇门。

▎ **神话传说与上古时代**

1. 盘古开天辟地、女娲补天造人——这些神话传说的背后反映了华夏文明什么样的世界观？

2. "三皇五帝"到底是哪三皇、哪五帝？伏羲和神农是各版本都公认的——他们分别贡献了什么？

3. 炎黄之战和炎黄战蚩尤——"炎黄子孙"的称呼是从这两场战争来的。

4. 尧舜禹"禅让制"——禹死后儿子启继承王位，"公天下"变成"家天下"。


▎ **夏朝**

1. 夏朝真的是中国第一个王朝吗？二里头遗址被认为是夏朝都城——为什么国际上有学者不承认？

2. "太康失国"和"少康中兴"。


▎ **商朝**

1. 甲骨文是目前发现的中国最早的系统性文字。

2. 商朝为什么盛行人祭？到了周朝为什么彻底废除？

3. 纣王有几分是被周朝"抹黑"的？


▎ **西周**

1. 牧野之战"前徒倒戈"的真实性有多大？

2. 西周分封制和欧洲中世纪的封建制有什么本质区别？

3. 周公制礼作乐为什么奠定了中华文明两千年的文化底色？

4. "共和行政"——公元前 841 年是中国历史确切纪年的开始。


▎ **东周 / 春秋**

1. 平王东迁后周天子权威下降的根本原因是什么？

2. 齐桓公"尊王攘夷"为什么能让诸侯听他的？

3. 孔子周游列国 14 年不被重用，但他的思想主导了中国两千多年。

4. "三家分晋"为什么被司马光选为《资治通鉴》开篇？

5. 老子"无为"是什么都不做，还是顺应自然的规律？


▎ **战国**

1. 为什么是秦国统一了天下？商鞅变法有没有"制度降维打击"的效果？

2. "远交近攻"在地缘政治上为什么有效？

3. 长平之战坑杀 40 万——这个数字可信吗？

4. 诸子百家为什么在春秋战国爆发？


▎ **秦朝**

1. "书同文、车同轨、行同伦"——如果没有这些统一措施，中国会不会像欧洲一样分裂？

2. 废除分封制、推行郡县制——为什么是革命性的？

3. 焚书坑儒有没有被后世夸大？

4. 秦朝为什么只存在了 15 年？


▎ **汉朝（西汉）**

1. 刘邦"布衣天子"的身份对他治国方式有什么影响？

2. "文景之治"的"无为而治"在治国层面到底意味着什么？

3. 汉武帝"独尊儒术"——是儒家学说本身，还是"外儒内法"？

4. 张骞通西域——丝绸之路不止丝绸，还有什么？

5. "轮台罪己诏"——皇帝公开认错，对后世有什么示范作用？


▎ **汉朝（东汉）**

1. 王莽改革为什么全失败了？是因为太超前还是书生治国？

2. 光武帝刘秀为什么能同时做到"开国"和"中兴"？

3. 东汉外戚和宦官交替专权的死循环。

4. 班超以 36 人定西域。


▎ **三国**

1. 黄巾起义为什么成了东汉灭亡的导火索？

2. 官渡之战——如果袁绍赢了，历史会如何走向？

3. 赤壁之战——如果曹操赢了，中国会提前统一吗？

4. 诸葛亮明知魏国国力数倍于蜀，为什么还要坚持北伐？

5. 西晋只存在了 50 年——"得国不正"是短命的原因吗？


▎ **两晋 / 南北朝**

1. "八王之乱"的直接原因是什么？

2. "五胡乱华"——这些"汉化"了的游牧民族打进来后，是选择全盘汉化还是保持自己的文化？

3. "淝水之战"——苻坚统一北方速度太快，还没来得及消化就南征了？

4. 北魏孝文帝"全盘汉化"——加速民族融合 vs 引起六镇叛乱。

5. 南北朝"门阀政治"跟欧洲中世纪的贵族政治有什么异同？


▎ **隋朝**

1. 隋文帝杨坚的三省六部制对后世的影响。

2. 隋炀帝修大运河——"当时是暴政、后世是伟业"。

3. 隋炀帝三征高句丽为什么全部失败？

4. 隋朝 38 年跟秦朝一样是"统一短命王朝"。


▎ **唐朝（初唐）**

1. 玄武门之变——李世民夺权，还是李建成先动了杀心？

2. "贞观之治"——"水能载舟、亦能覆舟"。

3. 三省六部制的"集体宰相"比秦汉的"独相"好在哪？

5. 唐太宗被尊"天可汗"。

4. 李白、杜甫、王维——为什么同一个时代能同时出现风格迥异的顶级诗人？
