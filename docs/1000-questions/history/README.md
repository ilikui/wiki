## 学习主线：从时间线到制度史

### 1. 时代脉络
- 从神话时代、早期国家到商周之交：如何区分传说、考古证据与可核实史料？
- 从分封制到郡县制：秦汉的国家治理结构发生了什么变化？
- 从门阀到科举：隋唐制度如何改变社会流动？
- 从坊市到夜市：宋代城市、商业与社会生活有哪些变化？
- 从陆权到海权：郑和下西洋、海禁与近代中外交流如何理解？
- 从传统社会到现代转型：1840 年以来的制度、经济与社会变化如何串联？

### 2. 交叉专题索引
1. 政治制度与官制：三公九卿、三省六部、内阁与军机处。
2. 财政与经济制度：赋税、货币、土地、商业及财政对国家能力的影响。
3. 军事与战争：从早期战争到近现代战争，比较战争组织和资源动员。
4. 思想与宗教：百家争鸣、儒释道互动及近代西学传播。
5. 科技、工程与建筑：四大发明、都江堰、大运河、长城及现代科技工程。
6. 文化、艺术与典籍：诗词书画、青铜器、瓷器、纸张和印刷。
7. 社会生活与人口迁徙：城市化、移民、宗族、饮食、服饰与审美。
8. 中外交流与疆域变迁：张骞、玄奘、郑和、利玛窦及全球化。

## 历史问题的研究方法

### 先拆事实，再讨论评价
- 事实层：发生了什么、时间地点是什么、涉及哪些人物与制度？
- 解释层：为什么发生？有哪些相互竞争的因果解释？
- 评价层：采用什么评价标准？不同群体、时代与史家如何看待？
- 证据层：每个关键结论至少关联一条可核验史料；推断与争议应明确标记。

### 比较历史与工程系统
- 春秋战国的多元竞争可作为标准尚未统一时期的类比，但类比不是史实证据。
- 秦的文字与交通制度统一可用于讨论公共基础设施与标准化；应同时关注其治理代价和历史条件。
- 财政可以作为理解国家治理的重要切入点，但不能将单一因素当作解释王朝兴衰的万能答案。

## 自检问题
1. 能否按顺序概述主要时代，并为每个时代列出关键事件、人物和制度？
2. 能否区分史料直接记载、后世解释和现代推断？
3. 对一个有争议的历史人物，能否列出支持与反对观点及其证据？
4. 能否解释财政、军事、制度和社会结构之间的相互作用？
5. 能否用多来源交叉验证，而不是只凭单一故事下结论？
