## 一、高等数学

### 极限与连续
1. 极限的 ε-δ 定义究竟表达了什么？为什么“无限接近”要用任意小的数刻画？
2. 两个重要极限分别有什么直觉，为什么重要？
3. 连续与不连续如何从极限理解？间断点有哪些类型？

### 导数与微分
1. 导数的几何意义是什么？为什么 (f'(x)=0) 不一定能推出极值？
2. 罗尔、拉格朗日、柯西中值定理有什么联系？
3. 洛必达法则何时适用、何时不适用？泰勒展开的局部近似思想是什么？

### 积分、重积分与微分方程
1. 定积分如何由黎曼和定义，为什么可以计算面积与体积？
2. 二重积分改变积分次序时，如何确定积分区域和上下限？
3. 极坐标变换为什么出现雅可比因子 (r)？
4. 一阶线性微分方程的积分因子在做什么？
5. 级数通项趋于零为何仍不足以保证级数收敛？

## 二、线性代数

### 矩阵、向量空间与线性变换
1. 矩阵乘法为何不是逐元素相乘？为什么通常不满足交换律？
2. 线性相关、基、维数与线性变换之间是什么关系？
3. 核与像分别描述线性变换的什么性质？

### 正交、特征值与分解
1. 为什么正交投影是最小二乘中的最佳逼近？
2. 特征值与特征向量描述矩阵的什么行为？为何 (Av=lambda v) 的乘法顺序重要？
3. 哪些矩阵可以对角化？Jordan 标准型解决什么问题？
4. SVD 与特征值分解有什么区别？为什么 SVD 适用范围更广？
5. 条件数、病态矩阵与数值稳定性如何影响实际计算？

### 工程连接
- 矩阵变换与坐标系转换：Park 变换、DBC 解析及 RTE 相关场景。
- 矩阵与信号处理：PCA、最小二乘、QR/Cholesky 分解。
- 矩阵与状态机：马尔可夫链的转移矩阵、稳态分布和特征向量。

## 三、概率论与数理统计

1. 条件概率、全概率公式和贝叶斯公式如何相互联系？
2. 事件互斥与独立能否同时成立？
3. 为什么连续随机变量在单点处的概率为零？概率为零是否等于不可能？
4. 期望、方差、协方差和相关系数分别刻画什么？
5. 大数定律和中心极限定理的结论与适用条件有什么区别？
6. 为什么样本方差通常使用 (n-1) 作分母？
7. 95% 置信区间应如何正确解释？
8. p 值小于 0.05 是否等于证明备择假设为真？
