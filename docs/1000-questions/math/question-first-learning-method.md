# 考研数学专题｜堆问题法：先列问题还是先学原理

> 来源：[Flomo 原始笔记](https://v.flomoapp.com/mine/?memo_id=MjQ5MDI4Mjk3)  
> 系列导航：[考研数学 1000 问全景](https://v.flomoapp.com/mine/?memo_id=MjQ2Mzc0OTc2)

## 矛盾

堆问题法先列问题再找答案，数学学习经典路径是先学原理再做习题，顺序看起来相反。关键在于按知识形态选择方法。

## 三类知识

1. **定义型知识——“这是什么”**：如特征值的定义。需要先快速了解定义，再围绕概念提出问题，因为词义来自定义本身。
2. **关系型知识——“A 和 B 有什么关系”**：只知道概念名称时也能提出问题，带着问题查资料。例如 DCM 和 DEM 的关系。
3. **应用型知识——“这个定理能解决什么问题”**：通常要先学原理，才能提出有质量的应用问题。例如不知道最小二乘法是什么，就很难列出它的真实应用场景。

## 建议流程

1. 快速浏览定义，不深究。
2. 列出定义型和关系型问题。
3. 带着问题阅读原理。
4. 回答问题列表。
5. 学完原理后，再提出应用型问题。
6. 定期回顾，并把重复遇到的问题向更深层拆解。

## 核心结论

1000 问学习法的卡点往往不是问题本身，而是问题类型和提出时机不匹配。第一轮优先定义型、关系型问题，第二轮再扩展应用型问题。
