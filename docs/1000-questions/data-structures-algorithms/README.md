# 数据结构与算法 1000问｜问题清单

> 来源：[Flomo 原笔记](https://v.flomoapp.com/mine/?memo_id=MjQ1NzM1Mjc4) · 原文 1,785 字

记录数据结构与算法学习的1000个问题：

▎ **基础概念**

1. 数据结构和算法之间是什么关系？同一个数据结构的两种不同操作，算是两种算法吗？

2. 什么是算法的"时间复杂度"？O(n)、O(log n)、O(n²)在实际运行时差了多少？

3. 什么是"空间换时间"？举一个你在嵌入式或C开发里实际见过的例子。


▎ **数组与链表**

1. 数组支持O(1)随机访问，链表是O(n)——那为什么还会有人用链表？链表的什么操作比数组快？

2. 单向链表、双向链表、循环链表——嵌入式开发里最常见的是哪一种？为什么？

3. 数组扩容（动态数组）是怎么实现的？为什么每次扩容通常翻倍而不是加一个固定大小？


▎ **栈与队列**

1. 栈（stack）为什么叫"后进先出"？函数调用栈正好就是栈结构——这个巧合说明了什么？

2. 队列（queue）在嵌入式系统里最常见的应用场景是哪里？环形缓冲区（ring buffer）是怎么用数组实现一个队列的？

3. 优先队列（priority queue）和普通队列的区别是什么？它在任务调度里扮演了什么角色？


▎ **树与二叉树**

1. 为什么"树"结构在计算机里这么常见？递归定义的数据结构和递归定义的问题之间是什么关系？

2. 二叉树的"前序、中序、后序"遍历——三种顺序分别输出了什么？为什么中序遍历一棵二叉搜索树得到的是有序序列？

3. 二叉搜索树（BST）在理想情况下查找是O(log n)——但在什么情况下它会退化成链表？

4. 为什么需要平衡二叉树（如AVL树、红黑树）？"旋转"操作是怎么恢复平衡的？

5. B树和B+树为什么在数据库和文件系统里被大量使用而非二叉搜索树？


▎ **堆**

1. 堆（heap）作为数据结构，和操作系统的"堆"是同一个概念吗？它们为什么都叫"堆"？

2. 二叉堆的插入和删除为什么是O(log n)？"上浮"和"下沉"操作各在做什么？

3. 堆排序（heapsort）是怎么做到的？它比快速排序好在哪、差在哪？


▎ **哈希表**

1. 哈希表为什么能实现平均O(1)的查找？"哈希函数"把一个任意输入映射到固定范围——这个映射一定会丢信息吗？

2. 哈希冲突怎么办？开放地址法和链地址法各有什么优缺点？

3. 负载因子（load factor）是什么？它到0.75和到0.95时，哈希表的性能会有什么不同？

4. 一致性哈希（consistent hashing）解决了什么分布式问题？为什么说它"最小化了重新映射"？


▎ **图**

1. 图的深度优先搜索（DFS）和广度优先搜索（BFS）各自适合解决什么问题？

2. 有向图和"拓扑排序"——什么场景下你会对一组有依赖关系的任务做拓扑排序？

3. 最短路径算法（Dijkstra）为什么要求边的权重非负？如果有负权边，该怎么办？

4. 最小生成树（MST）——Kruskal算法和Prim算法各自在什么图结构上更高效？


▎ **排序算法**

1. 快速排序在最坏情况下是O(n²)——那为什么绝大部分情况下还是用快排而不是理论上更稳定的归并排序？

2. 归并排序的"分治"思想是什么？它为什么天然适合外排序（数据太大没法全放内存）？

3. 计数排序和桶排序在什么条件下能比O(n log n)更快？它们利用了输入数据的什么性质？

4. 为什么稳定排序在排序对象是复杂结构时很重要？（比如先按姓名排、再按年龄排）


▎ **搜索与递归**

1. 二分查找为什么要求数据是已排序的？如果数据没排序就用二分，会得到什么结果？

2. 回溯算法（backtracking）和暴力枚举的本质区别是什么？"剪枝"在做什么？

3. 分治和动态规划的区别是什么——什么时候一个问题能"分"不能"DP"？


▎ **动态规划入门**

1. 什么样的问题适合用动态规划？"最优子结构"和"重叠子问题"到底在说什么？

2. 斐波那契数列的递归实现（递归树）和DP实现（填表）——为什么一个指数爆炸一个线性？

3. 0/1背包问题——如果物品不可分割，你怎么决定塞哪些进背包？"装或不装"的决策树怎么剪枝？
