## 知识如何生长

```mermaid
flowchart TD
    A[捕获灵感与问题] --> B[归入专题]
    B --> C[拆解概念与原理]
    C --> D[编写答案和示例]
    D --> E[通过实践或来源验证]
    E --> F[建立关联并发布]
    F --> G[复习、去重、持续修订]
    G --> B
```

## 内容原则

- **来源可追溯：** 保留原始笔记、参考资料和上下文。
- **问题可连接：** 通过专题索引和相对路径链接形成知识网络。
- **结论可验证：** 区分待整理、初稿、已复核与已验证内容。
- **结构可扩展：** 每个专题维护独立页面，避免单页无限膨胀。
- **内容可迁移：** 优先使用 Markdown，便于 GitHub 浏览和 MkDocs 构建。

> 本知识库持续演进中。专题入口不代表所有问题均已回答；每份内容以页面中的来源、状态和验证记录为准。
