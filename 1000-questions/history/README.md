**读法·历史三问：**

**其一：历史朝代 vs 汽车电子——春秋战国→标准混战期，秦→CAN总线统一，宋→软件定义汽车**

春秋战国百家争鸣 → AUTOSAR 标准化之前 Tier1 各自为政（2010 年前每家 Tier1 有自己的架构/接口/工具链）。行业从"各自定义标准"到"统一框架"——不是技术最好决定的，是效率到达临界点后"不用共同标准就做不下去了"。秦朝书同文车同轨 → CAN 总线统一汽车通信协议：统一底层基础设施，上层保留差异。宋朝重文轻武 → 软件定义汽车：软件团队话语权上升，隐忧是硬件能力退化。

**其二：财政 = 历代王朝的"系统总线"——读懂财政就懂一个朝代 70% 的运行逻辑**

财政 → 官制（收入决定养多少官员）、财政 → 军事（军费占历代财政 60-70%，赤字→加税→起义→恶性循环）、财政 → 文化（财政紧张时第一个砍"养士"开支）。官制跟文化/技术交叉少，技术缓慢积累——只有财政是牵一发动全身的枢纽。

**其三：堆问题法在历史——开放式问题拆"事实层/评价层"**

技术问题（CAN 终端电阻为什么 120Ω）有标准答案；历史问题（秦始皇是功是过）没有唯一答案。处理：事实层子问题有标准答案、评价层附"对立史料"链接、没有史料支撑的推断标注"待考"。纪律：每个问题的答案至少 1 条明确史料支撑。历史卡片不写"标准答案"——写成"当前理解 + 用了什么史料 + 还有什么争议"。
