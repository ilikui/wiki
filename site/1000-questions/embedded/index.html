    嵌入式 1000问｜全景导航与问题清单¶

    来源：Flomo 嵌入式 1000问导航。原文约 16829 字；本页保留原始导航与问题清单，导航中列出的专题文章仍需逐篇迁移和核验。

    专栏⑮·导航：嵌入式 1000 问全景——从裸机到驱动的完整地图

    📎 专栏⑭C语言导航 → https://v.flomoapp.com/mine/?memo_id=MjQ1NzM0NTk5

    📎 专栏⑬硬件导航 → https://v.flomoapp.com/mine/?memo_id=MjQ3NTQ2MDE3

    ▎目录（10篇）

    1. 上电到 main()——启动文件、向量表、栈指针，Bootloader 跳 APP 的三个坑

    2. 时钟配置——HSE→PLL→SYSCLK，顺序乱了 MCU 就 hang

    3. PWM 与定时器——ARR/PSC/CCR 的关系，一个公式算清频率和占空比

    4. 链接脚本——内存地图、段分配、LMA/VMA，5 个最常见的 .ld 错误

    5. 单片机学习路径——4 阶段：裸机筑基→寄存器级外设→综合项目→RTOS

    6. 基础概念与架构——嵌入式 vs 通用计算机、MCU vs MPU、冯诺依曼 vs 哈佛

    7. 中断与 ISR——中断延迟、嵌套、临界区，ISR 为什么越短越好

    8. 嵌入式 Linux 驱动入门——字符设备、设备树、file_operations、下半部

    9. 嵌入式调试三板斧——HardFault 定位、printf 的坑、示波器 vs 逻辑分析仪

    10. 嵌入式 15 项自检清单——上车前逐项打勾

    ▎设计原则

    • 每条问题从"软件工程师真实踩坑"出发，不写教科书复述

    • 90+ 方向的问题库作为全景索引，每篇深挖一个方向的实战

    • 与 AUTOSAR（专栏①-⑩）、C语言（⑭）、硬件（⑬）互链，嵌入式是承上启下的主线

    ▎1000 问全景（问题库）

    基础概念

    1. 嵌入式系统和通用计算机系统最本质的区别是什么？这个区别决定了哪些设计上的不同？

    2. MCU和MPU的核心区别是什么？什么时候该选MCU，什么时候该选MPU？

    3. 冯诺依曼结构和哈佛结构在嵌入式系统里怎么体现？STM32是哪一种？

    4. 为什么嵌入式软件经常要跟"寄存器"打交道？读写寄存器和读写普通内存有什么不同？

    处理器与架构

    1. Cortex-M3的"三级流水线"是哪三级？它和Cortex-A系列的处理器的流水线有什么不同？

    2. 什么是"向量表"？中断来了以后CPU怎么从向量表找到对应的处理函数？

    3. ARM的Thumb指令集和Thumb-2是什么？为什么嵌入式里经常用Thumb而不是ARM指令集？

    4. RISC-V和ARM在架构设计哲学上有什么关键区别？为什么RISC-V近年发展这么快？

    5. 大端和小端（Big-endian / Little-endian）在嵌入式开发中什么时候会出问题？

    存储器与链接

    1. 嵌入式系统的存储层级（SRAM、Flash、SDRAM、EEPROM）各有什么特点？代码放哪、数据放哪？

    2. 链接脚本（Linker Script）在做什么？为什么嵌入式开发要自己写.ld文件？

    3. 堆和栈在嵌入式系统里分别在哪？栈溢出了一般会发生什么？怎么预防？

    4. MMU和MPU有什么区别？什么场景下嵌入式系统需要MMU？

    GPIO与外设

    1. GPIO的推挽输出和开漏输出有什么区别？什么场景下必须用开漏？

    2. 为什么UART要设波特率？收发双方的波特率差多少会出错？

    3. I2C为什么需要上拉电阻？它的"开漏"设计跟UART的推挽设计各自解决了什么问题？

    4. SPI和I2C在什么场景下选哪个？为什么说SPI比I2C快？

    5. ADC的采样率、分辨率和精度之间是什么关系？一个12位的ADC是不是一定比10位的"准"？

    中断与异常

    1. 中断和异常的区别是什么？按中断向量表和异常向量表来区分的话，它们各自的入口在哪？

    2. 中断服务函数（ISR）为什么越短越好？如果必须做耗时操作，有哪些处理方式？

    3. 中断嵌套会发生什么？什么时候应该允许中断嵌套，什么时候应该禁止？

    4. 中断优先级和子优先级（如STM32的NVIC分组）——为什么要分成两组？怎么配置？

    5. 临界区（critical section）是什么？为什么在ISR里和任务里保护临界区的方式不一样？

    定时器

    1. 定时器的本质是什么？一个定时器"溢出"时发生了什么？

    2. 通用定时器和高级定时器（如STM32的TIM和TIM1/8）在哪些功能上有差别？什么场景必须用高级定时器？

    3. PWM是怎么通过定时器产生的？占空比和频率各由什么寄存器控制？

    4. 输入捕获和输出比较——一个是读、一个是写，各自的典型应用场景是什么？

    5. 看门狗定时器（WDT）为什么叫"看门狗"？如果程序跑飞了，它是怎么"咬"的？

    DMA

    1. DMA为什么能"不经过CPU"传输数据？那CPU在DMA工作期间在干什么？

    2. 什么时候该用DMA，什么时候直接CPU轮询或中断更合适？

    3. DMA的循环模式（circular mode）和普通模式有什么区别——什么时候需要循环？

    4. DMA传输完成的中断比普通外设中断在实时性上有什么不同？

    低功耗

    1. 嵌入式系统的三种功耗模式（Sleep/Stop/Standby）分别在关什么？从Stop唤醒比从Standby快的原因是什么？

    2. 什么时候应该进入低功耗模式？频繁进出低功耗反而更耗电——这个阈值怎么判断？

    3. 低功耗设计不只是软件的事——外围电路（如GPIO上拉电阻、供电LDO的选择）在低功耗里起了什么作用？

    RTOS（实时操作系统）

    1. FreeRTOS的任务调度是靠什么机制切换任务的？为什么叫"抢占式调度"？

    2. 任务状态机（就绪、运行、阻塞、挂起）——一个任务在这四个状态之间是怎么跳转的？

    3. 信号量（Semaphore）和互斥量（Mutex）的区别是什么？什么场景下用错会出问题？

    4. 消息队列和邮箱的本质区别是什么？如果要在多个任务之间传一组结构化数据，选哪个？

    5. 什么是优先级反转？FreeRTOS怎么处理这个问题？

    6. FreeRTOS的Tickless模式是干什么的？它和低功耗模式怎么配合？

    Bootloader

    1. Bootloader的作用是什么？为什么嵌入式系统要有Bootloader而不是直接跑应用程序？

    2. 常见的"二级Bootloader"是怎么启动的？从ROM Boot→Bootloader→Application的跳转过程是怎样的？

    3. Bootloader做固件更新时，怎么保证更新中途掉电了还能恢复？

    4. Bootloader怎么用CRC或校验和来验证固件的完整性？如果校验失败怎么办？

    5. Bootloader和应用代码在Flash里怎么分区？两个区域的地址边界谁来定？

    嵌入式Linux / 驱动

    1. Linux内核驱动的"字符设备"和"平台设备"有什么区别？什么时候该写哪一类？

    2. 设备树（Device Tree）是干什么的？以前没有设备树的时候怎么描述硬件？

    3. GPIO驱动程序里，request、direction_output、direction_input这几个操作各对应硬件上的什么动作？

    4. 中断下半部（Bottom Half）为什么需要？Tasklet、Workqueue、Threaded IRQ各自适合什么场景？

    5. 用户空间的open/read/write系统调用是怎么一步步到达硬件寄存器的？驱动模型里的file_operations结构体是干什么的？

    调试与工具

    1. JTAG和SWD有什么区别？为什么STM32上SWD只用了两根线？

    2. printf调试和断点调试各自的优缺点——在实时嵌入式系统里，为什么printf本身可能改变问题的表现？

    3. 逻辑分析仪和示波器在嵌入式调试中各自看什么？什么场景下选逻辑分析仪，什么场景选示波器？

    4. 当程序跑飞了（HardFault）——一般第一步做什么来确定是哪里出了问题？

    通信协议深入

    1. CAN总线为什么需要120Ω终端电阻？如果没接或少接一个，实际通信中会出现什么现象？

    2. CAN FD和Classic CAN在帧格式上有什么关键区别？为什么CAN FD能传更多数据还更快？

    3. LIN总线为什么是"低成本CAN"的定位？它的主从架构跟CAN的多主架构比，各适合什么场景？

    4. SPI的片选（CS）信号在多个从设备时怎么管理？如果片选信号抖动了一下，会发生什么？
