    ▎ 一、神话传说与上古（？—约前2070年）

    • 盘古开天、女娲造人、三皇五帝

    • 炎黄之战、尧舜禹禅让

    • 奠定华夏文明世界观

    • 专题：宗教史（上古信仰）、文化史（神话起源）

    ▎ 二、夏朝（约前2070—前1600年）

    • 禹传启→"公天下"变"家天下"

    • 二里头遗址（夏都？）

    • 最早的世袭王朝

    • 专题：制度史（世袭制开端）

    ▎ 三、商朝（约前1600—前1046年）

    • 甲骨文（最早系统文字）

    • 人祭/人殉盛行

    • 青铜文明巅峰（司母戊鼎）

    • 纣王亡国（周人"抹黑"？）

    • 专题：文化史（甲骨文）、艺术工艺史（青铜器）、典籍史（甲骨文献）

    ▎ 四、西周（前1046—前771年）

    • 牧野之战（前徒倒戈）

    • 分封制（封建亲戚）

    • 周公制礼作乐

    • 共和行政（前841年——中国确切纪年开始）

    • 专题：制度史（分封/宗法/礼乐）、宗教史（"天命"思想）、军事史（牧野之战）

    ▎ 五、东周·春秋（前770—前476年）

    • 平王东迁→周天子权威衰落

    • 齐桓公"尊王攘夷"（春秋首霸）

    • 孔子（前551-479）周游列国

    • 老子《道德经》

    • 专题：思想史（百家争鸣开端/儒道起源）、军事史（争霸战争）、中外交流史（华夏-戎狄互动）

    ▎ 六、东周·战国（前475—前221年）

    • 三家分晋→战国七雄

    • 商鞅变法（秦国崛起）

    • 长平之战（坑杀40万）

    • 诸子百家（儒/道/法/墨/兵/纵横/阴阳）

    • 专题：思想史（百家争鸣高峰）、军事史（长平之战）、制度史（郡县制开端）、经济史（商鞅废井田）

    ▎ 七、秦朝（前221—前207年）

    • 秦始皇统一六国

    • 书同文/车同轨/行同伦/统一度量衡

    • 废除分封→郡县制

    • 焚书坑儒

    • 15年灭亡（二世而亡）

    • 专题：制度史（郡县制/三公九卿）、地理史（三十六郡）、建筑史（长城/阿房宫/始皇陵）、典籍史（焚书）

    ▎ 八、西汉（前202—公元9年）

    • 刘邦布衣天子→"无为而治"（文景之治）

    • 汉武帝"独尊儒术"（外儒内法）

    • 张骞通西域（丝绸之路）

    • 司马迁《史记》

    • 轮台罪己诏

    • 专题：中外交流史（张骞/丝绸之路）、思想史（罢黜百家/天人感应）、经济史（盐铁专营/五铢钱）、地理史（扩张/河西四郡）、军事史（汉匈战争）

    ▎ 九、东汉（25—220年）

    • 光武中兴（刘秀开国+中兴）

    • 外戚宦官交替专权（死循环）

    • 班超定西域

    • 蔡伦改进造纸术

    • 张仲景《伤寒杂病论》

    • 专题：科技史（造纸术/地动仪/医学）、宗教史（佛教传入/白马寺）、社会史（豪强崛起/门阀萌芽）

    ▎ 十、三国（220—280年）

    • 官渡之战/赤壁之战/夷陵之战

    • 诸葛亮北伐

    • 三国归晋

    • 专题：军事史（三大战役）、思想史（玄学萌芽）

    ▎ 十一、两晋/南北朝（265—589年）

    • 西晋统一（50年短命）→八王之乱→五胡乱华

    • 淝水之战（苻坚80万vs谢玄8万）

    • 北魏孝文帝汉化改革

    • 门阀政治（"上品无寒门"）

    • 佛教大规模流行/云冈龙门石窟

    • 专题：民族史（五胡入华/汉化）、思想史（玄学/佛教本土化）、艺术史（石窟/顾恺之/王羲之）、经济史（均田制）、人口史（永嘉南渡）

    ▎ 十二、隋朝（581—618年）

    • 三省六部制

    • 大运河（"当时是暴政，后世是伟业"）

    • 三征高句丽失败

    • 37年短命王朝（跟秦一样：统一+短命+大工程+二世而亡）

    • 专题：制度史（三省六部/科举开端）、建筑史（大运河/长安城）、地理史（重新统一）

    ▎ 十三、唐朝·初唐（618—755年）

    • 玄武门之变→贞观之治

    • 三省六部成熟/"天可汗"

    • 安西都护府（西域统治）

    • 专题：制度史（三省六部/科举）、中外交流史（丝绸之路/长安国际大都市）、军事史（安西都护府/怛罗斯之战）

    ▎ 十四、唐朝·盛唐（712—755年）

    • 武则天（唯一女皇）→开元盛世

    • 长安百万人口/万国来朝

    • 李白/杜甫/王维（诗歌巅峰）

    • 专题：文化史（唐诗巅峰/颜真卿/吴道子）、社会史（开放风气/女性地位）、服饰史（开放/胡服流行/袒胸装）

    ▎ 十五、唐朝·中晚唐（755—907年）

    • 安史之乱（"渔阳颦鼓动地来"）

    • 藩镇割据/宦官专权

    • 牛李党争

    • 黄巢起义→朱温篡唐

    • 专题：军事史（安史之乱）、地理史（疆域萎缩）

    ▎ 十六、五代十国（907—960年）

    • 兵变上位→再被兵变推翻的死循环

    • 石敬瑭割让燕云十六州（影响北宋300年）

    • 柴荣改革（为赵匡胤铺路）

    • 专题：军事史（燕云十六州的战略意义）、民族史（契丹崛起）

    ▎ 十七、北宋（960—1127年）

    • 陈桥兵变→杯酒释兵权→重文轻武

    • 澶渊之盟（花钱买和平）

    • 庆历新政/熙宁变法（范仲淹/王安石）

    • 司马光《资治通鉴》

    读法·历史三问：

    其一：历史朝代 vs 汽车电子——春秋战国→标准混战期，秦→CAN总线统一，宋→软件定义汽车

    春秋战国百家争鸣 → AUTOSAR 标准化之前 Tier1 各自为政（2010 年前每家 Tier1 有自己的架构/接口/工具链）。行业从"各自定义标准"到"统一框架"——不是技术最好决定的，是效率到达临界点后"不用共同标准就做不下去了"。秦朝书同文车同轨 → CAN 总线统一汽车通信协议：统一底层基础设施，上层保留差异。宋朝重文轻武 → 软件定义汽车：软件团队话语权上升，隐忧是硬件能力退化。

    其二：财政 = 历代王朝的"系统总线"——读懂财政就懂一个朝代 70% 的运行逻辑

    财政 → 官制（收入决定养多少官员）、财政 → 军事（军费占历代财政 60-70%，赤字→加税→起义→恶性循环）、财政 → 文化（财政紧张时第一个砍"养士"开支）。官制跟文化/技术交叉少，技术缓慢积累——只有财政是牵一发动全身的枢纽。

    其三：堆问题法在历史——开放式问题拆"事实层/评价层"

    技术问题（CAN 终端电阻为什么 120Ω）有标准答案；历史问题（秦始皇是功是过）没有唯一答案。处理：事实层子问题有标准答案、评价层附"对立史料"链接、没有史料支撑的推断标注"待考"。纪律：每个问题的答案至少 1 条明确史料支撑。历史卡片不写"标准答案"——写成"当前理解 + 用了什么史料 + 还有什么争议"。
